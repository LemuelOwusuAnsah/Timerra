# Timerra

A modern, clean countdown timer application built with vanilla JavaScript. Create events, track time remaining in days, hours, minutes, and seconds, and never miss a special moment again.

## Features

**Core Functionality**
- Create events with custom names and dates
- Real-time countdown display (days, hours, minutes, seconds)
- Select and switch between multiple events
- Delete events you no longer need
- Events saved to localStorage for persistence

**User Interface**
- Clean glass-morphism design
- Dark and light mode support
- Fully responsive on all devices
- Keyboard-friendly (Enter to submit)

**Technical Details**
- Pure vanilla JavaScript
- No external dependencies
- LocalStorage for data persistence
- Smooth 60fps countdown animations
